Отлично! Давай сделаем так, чтобы и FFmpeg, и Tesseract работали корректно на Windows с русским видео и текстом. Я дам пошагово.

1. Исправляем путь к видео для FFmpeg

FFmpeg плохо работает с русскими символами в пути. Сделаем так:

Создай папку, например:

C:\Videos\


Скопируй видео туда и переименуй, чтобы имя файла было на английском, например:

video.mp4


Используй кавычки в команде FFmpeg, чтобы путь точно распознался:

ffmpeg -i "C:\Videos\video.mp4" "C:\Videos\video_output.mp4"

2. Настраиваем Tesseract для русского языка

Скачай файл rus.traineddata с официального репозитория:
https://github.com/tesseract-ocr/tessdata

Создай папку для данных Tesseract, например:

C:\Tesseract\tessdata


Помести файл rus.traineddata в эту папку.

Укажи переменную окружения для Windows, чтобы Tesseract знал, где искать языковые файлы:

set TESSDATA_PREFIX=C:\Tesseract\tessdata\


Проверка установки:

tesseract --list-langs


Если всё верно, увидишь rus в списке.

3. Пример команды Tesseract для распознавания русского текста
tesseract "C:\Videos\video_output.png" "C:\Videos\output_text" -l rus


"C:\Videos\video_output.png" — картинка или кадр из видео

"C:\Videos\output_text.txt" — результат распознавания будет в этом файле

💡 Совет: Если видео большое, сначала с помощью FFmpeg извлекай кадры, а потом распознавай текст по ним.
Пример команды для извлечения кадров:

ffmpeg -i "C:\Videos\video.mp4" -vf fps=1 "C:\Videos\frame_%04d.png"


Это создаст кадры с частотой 1 кадр в секунду.
