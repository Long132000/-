Запуск
Убедитесь, что установлены библиотеки: pip install Pillow openpyxl

Скопируйте код в файл main.py.

Создайте папку images и положите туда picture.png (любую картинку-заглушку).

(Опционально) положите файлы импорта в папку import_data.

Запустите python main.py.

Тестовые пользователи (если импорта нет):

admin / admin – администратор

manager / manager – менеджер

client / client – клиент
