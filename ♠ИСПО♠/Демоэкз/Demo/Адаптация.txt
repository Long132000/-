📌 Таблицы, которые могут меняться:
Что нужно изменить	Где находится	Примеры
Название таблицы products	CREATE TABLE products	Может быть materials, books, food
Название таблицы categories	CREATE TABLE categories	Может быть types, sections
Название таблицы suppliers	CREATE TABLE suppliers	Может быть manufacturers, vendors
Название таблицы orders	CREATE TABLE orders	Может быть purchases, sales
Поля в товарах	Внутри CREATE TABLE products	У вас могут быть: weight, color, size, material, author, pages
🔧 Как менять поля в таблице products:
sql
-- ВАШ ВАРИАНТ (игрушки) → НОВЫЙ ВАРИАНТ (стройматериалы)
CREATE TABLE products (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    name TEXT NOT NULL,                    -- ОСТАЁТСЯ
    description TEXT,                      -- ОСТАЁТСЯ
    category_id INTEGER NOT NULL,          -- ОСТАЁТСЯ
    manufacturer TEXT,                     -- ОСТАЁТСЯ
    supplier_id INTEGER NOT NULL,          -- ОСТАЁТСЯ
    price REAL NOT NULL,                   -- ОСТАЁТСЯ
    unit TEXT,                             -- ОСТАЁТСЯ
    quantity INTEGER NOT NULL,             -- ОСТАЁТСЯ
    discount REAL DEFAULT 0,               -- ОСТАЁТСЯ
    photo_path TEXT,                       -- ОСТАЁТСЯ
    -- ↓↓↓ ДОБАВЛЯЕТЕ СВОИ ПОЛЯ ↓↓↓
    weight REAL,                           -- вес (для стройматериалов)
    color TEXT,                            -- цвет
    material TEXT,                         -- материал
    size TEXT,                             -- размер
    country TEXT,                          -- страна производства
    FOREIGN KEY (category_id) REFERENCES categories(id),
    FOREIGN KEY (supplier_id) REFERENCES suppliers(id)
)

6️⃣ ИМПОРТ ДАННЫХ (если есть файлы)
Если в вашем варианте есть файлы для импорта (CSV, Excel), добавьте этот метод:

python
import csv

def import_from_csv(self, file_path):
    """Импорт товаров из CSV файла."""
    conn = get_db_connection()
    cur = conn.cursor()
    
    with open(file_path, 'r', encoding='utf-8') as f:
        reader = csv.DictReader(f, delimiter=';')
        for row in reader:
            # Получаем ID категории и поставщика
            cur.execute("SELECT id FROM categories WHERE name=?", (row['category'],))
            cat_id = cur.fetchone()[0]
            
            cur.execute("SELECT id FROM suppliers WHERE name=?", (row['supplier'],))
            sup_id = cur.fetchone()[0]
            
            # Вставляем товар
            cur.execute('''
                INSERT INTO products (name, description, category_id, supplier_id, price, quantity)
                VALUES (?, ?, ?, ?, ?, ?)
            ''', (row['name'], row['description'], cat_id, sup_id, float(row['price']), int(row['quantity'])))
    
    conn.commit()
    conn.close()
    messagebox.showinfo("Успех", "Данные импортированы")
