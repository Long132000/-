    var query = _context.Tours.Include(t => t.Country).AsQueryable();
    if (!string.IsNullOrEmpty(searchCountry))

## 🧠 Важно для всех вариантов

- Все навигационные свойства помечайте как `nullable` (`?`), чтобы избежать ошибок валидации при создании записей.
- Для всех столбцов типа `DateTime` в `OnModelCreating` добавляйте `.HasColumnType("timestamp without time zone")`.
- Имена таблиц и столбцов приводите к нижнему регистру через `HasColumnName`.
- В `Program.cs` используйте `EnsureDeleted()` + `EnsureCreated()` для чистой схемы при каждом запуске (для учебного проекта это удобно).

## ✅ Итог – что именно изменилось

| Компонент               | PostgreSQL                                 | SQLite                                      |
|-------------------------|--------------------------------------------|---------------------------------------------|
| **NuGet-пакет**         | `Npgsql.EntityFrameworkCore.PostgreSQL`    | `Microsoft.EntityFrameworkCore.Sqlite`      |
| **Строка подключения**  | `Host=...;Port=...;Database=...;Username=...` | `Data Source=examchik.db`                   |
| **Use-метод в Program** | `UseNpgsql(...)`                           | `UseSqlite(...)`                            |
| **Тип даты**            | `.HasColumnType("timestamp without time zone")`| можно убрать (работает без указания типа)    |
| **Удаление БД**         | дропает схему/таблицы                      | удаляет файл `.db`                          |

Все остальные части приложения остаются неизменными.  
Вы можете свободно переключаться между PostgreSQL и SQLite, меняя только указанные выше файлы.
