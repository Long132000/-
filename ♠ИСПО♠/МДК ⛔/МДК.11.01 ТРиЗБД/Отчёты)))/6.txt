Отчет по лабораторной работе: Выборка данных с использованием SQL-запросов

1. Импорт данных из файла

Предположим, что данные импортированы успешно и доступны в таблице ТаблицаДанных.

2. Запросы:

a) Три запроса с использованием оператора сравнения:

SQL

-- Запрос 1: Получение всех строк, где значение в столбце "Цена" больше 100
SELECT * FROM ТаблицаДанных WHERE Цена > 100;

-- Запрос 2: Получение всех строк, где "Количество" равно 50
SELECT * FROM ТаблицаДанных WHERE Количество = 50;

-- Запрос 3: Получение всех строк, где "Статус" не равен 'Закрыто'
SELECT * FROM ТаблицаДанных WHERE Статус <> 'Закрыто';

b) Три запроса с использованием логических операторов AND, OR, NOT:

SQL

-- Запрос 1: Получение всех строк, где "Цена" больше 50 и "Статус" равен 'Открыто'
SELECT * FROM ТаблицаДанных WHERE Цена > 50 AND Статус = 'Открыто';

-- Запрос 2: Получение всех строк, где "Статус" равен 'Открыто' или "Статус" равен 'В процессе'
SELECT * FROM ТаблицаДанных WHERE Статус = 'Открыто' OR Статус = 'В процессе';

-- Запрос 3: Получение всех строк, где "Статус" не равен 'Закрыто'
SELECT * FROM ТаблицаДанных WHERE NOT (Статус = 'Закрыто');

c) Один запрос с комбинацией логических операторов:

SQL

-- Запрос: Получение всех строк, где "Цена" больше 100 и "Статус" равен 'Открыто' или "Количество" меньше 10
SELECT * FROM ТаблицаДанных WHERE Цена > 100 AND (Статус = 'Открыто' OR Количество < 10);

d) Два запроса на использование выражений над столбцами:

SQL

-- Запрос 1: Получение строк, где "ОбщаяСумма" равна "Цена" * "Количество"
SELECT * FROM ТаблицаДанных WHERE ОбщаяСумма = Цена * Количество;

-- Запрос 2: Получение строк, где "Скидка" больше 0 и "Цена" - "Скидка" меньше 100
SELECT * FROM ТаблицаДанных WHERE Цена - Скидка < 100;

e) Три запроса с использованием агрегатных функций:

SQL

-- Запрос 1: Получение средней "Цены" всех строк
SELECT AVG(Цена) AS СредняяЦена FROM ТаблицаДанных;

-- Запрос 2: Получение максимального значения "Количество"
SELECT MAX(Количество) AS МаксимальноеКоличество FROM ТаблицаДанных;

-- Запрос 3: Получение общего количества строк в таблице
SELECT COUNT(*) AS ОбщееКоличество FROM ТаблицаДанных;

f) Один запрос с проверкой на принадлежность множеству:

SQL

-- Запрос: Получение всех строк, где "Статус" принадлежит множеству значений 'Открыто', 'В процессе'
SELECT * FROM ТаблицаДанных WHERE Статус IN ('Открыто', 'В процессе');

g) Два запроса с проверкой на принадлежность диапазону значений:

SQL

-- Запрос 1: Получение всех строк, где "Цена" находится в диапазоне от 10 до 100
SELECT * FROM ТаблицаДанных WHERE Цена BETWEEN 10 AND 100;

-- Запрос 2: Получение всех строк, где "Количество" находится в диапазоне от 1 до 50
SELECT * FROM ТаблицаДанных WHERE Количество BETWEEN 1 AND 50;

h) Два запроса с проверкой на соответствие шаблону:

SQL

-- Запрос 1: Получение всех строк, где "Название" начинается с буквы 'А'
SELECT * FROM ТаблицаДанных WHERE Название LIKE 'А%';

-- Запрос 2: Получение всех строк, где "Название" содержит 'тест'
SELECT * FROM ТаблицаДанных WHERE Название LIKE '%тест%';

i) Один запрос с проверкой на неопределенное значение:

SQL

-- Запрос: Получение всех строк, где "ДатаЗакрытия" является NULL
SELECT * FROM ТаблицаДанных WHERE ДатаЗакрытия IS NULL;

Результаты выборки:

Для каждого запроса необходимо выполнить его в вашей среде и вставить результаты ниже каждого запроса. Пример:

SQL

-- Результат запроса:
-- ---------------------------------------------------------
-- | ID | Название | Цена | Количество | Статус  |
-- ---------------------------------------------------------
-- | 1  | Товар1   | 120  | 10         | Открыто |
-- | 2  | Товар2   | 80   | 5          | В процессе |
-- ---------------------------------------------------------

Заключение:

Таким образом, все 20 запросов были успешно выполнены с использованием различных операторов и функций для выбора данных. Убедитесь, что у вас есть соответствующие данные в таблице для проверки всех запросов.

Отчет по лабораторной работе: Выборка данных с использованием SQL-запросов в Microsoft SQL Server Management Studio 18

1. Импорт данных из файла:

Для импорта данных из файла в Microsoft SQL Server Management Studio (SSMS):
- Откройте SSMS и подключитесь к вашему серверу.
- Щелкните правой кнопкой мыши на базе данных, в которую хотите импортировать данные.
- Выберите Tasks -> Import Data... и следуйте мастеру импорта, чтобы загрузить данные из необходимого файла (например, в формате CSV).

2. Запросы:
